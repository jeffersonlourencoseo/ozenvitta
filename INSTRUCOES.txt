PASSO 1: PREPARAR O ARQUIVO JSON DO PRODUTO
============================================================

Va em:
   nutraceutico-site/scripts/

Copie o arquivo:
   produto-template.json

Renomeie para o nome do seu produto. Exemplo:
   meu-produto.json

Abra o arquivo e preencha TUDO que esta em maiusculas:

   "nome": "NOME_DO_PRODUTO"              → "Vitacaps"
   "nomeSlug": "nome-do-produto"         → "vitacaps"
   "siteOficial": "https://siteoficial.com" → "https://vitacaps.com.br"
   "linkAfiliado": "SEU_LINK"             → "https://app.monetizze.com.br/r/ABC123"
   "precoPopular": "197.00"               → preco do kit mais popular
   "corTema": "#513F7E"                   → cor hexadecimal da marca
   "expertNome": "Dra. Nome"              → nome da especialista
   ...

DICA: Use o exemplo-produto.json como referencia.
      Ele esta todo preenchido com dados ficticios.

============================================================
PASSO 2: GERAR O SITE (DUAS FORMAS)
============================================================

FORMA A: Duplo clique (recomendado para leigos)
-----------------------------------------------

1. Va em: nutraceutico-site/scripts/
2. De um duplo clique em: GERAR-SITE.bat
3. Digite o nome do seu arquivo JSON
   Exemplo: meu-produto.json
4. Aperte ENTER
5. Aguarde a mensagem "GERACAO CONCLUIDA!"

FORMA B: Terminal (para quem conhece)
--------------------------------------

1. Abra o terminal na pasta: nutraceutico-site/scripts/
2. Digite:
      node create-new-site.js meu-produto.json
3. Aguarde o site ser gerado

RESULTADO:
   Sera criada uma pasta NOVA ao lado de nutraceutico-site.
   Exemplo: C:\Users\Jefferson\Desktop\SEO LOCAL\MONJAUX\vitacaps-site\

============================================================
PASSO 3: PREPARAR PALAVRAS-CHAVE (OBRIGATORIO)
============================================================

Na pasta do novo site (ex: vitacaps-site\), abra:

   KW-vitacaps.txt

Preencha com as palavras-chave que voce quer ranquear.
Use uma palavra por linha.

Exemplo:
   vitacaps funciona
   vitacaps funciona mesmo
   vitacaps emagrece
   vitacaps preco
   ...

DEPOIS DE PREENCHER, voce tem DUAS opcoes:

   OPCAO A (recomendada): Me envie o arquivo preenchido
            → Eu atualizo TODO o copy do site automaticamente

   OPCAO B: Edite voce mesmo
            → Abra cada arquivo .md em src/content/pages/
            → Troque as keywords genericas pelas suas
            → Faca o mesmo na index.astro

============================================================
PASSO 4: COLOCAR IMAGENS
============================================================

Dentro da pasta do novo site, va em:

   public/images/

Coloque as seguintes imagens (mantenha os nomes exatos):

   logo.png              → 200x50px, fundo transparente
   produto.jpg           → 800x800px, foto do produto
   og-default.jpg        → 1200x630px, Open Graph padrao
   og-o-que-e.jpg        → 1200x630px, OG da pagina "O que e"
   og-composicao.jpg     → 1200x630px, OG da pagina "Composicao"
   og-beneficios.jpg     → 1200x630px, OG da pagina "Beneficios"
   og-como-usar.jpg      → 1200x630px, OG da pagina "Como Usar"
   og-contraindicacoes.jpg → 1200x630px, OG da pagina "Contraindicacoes"
   og-depoimentos.jpg    → 1200x630px, OG da pagina "Depoimentos"
   og-onde-comprar.jpg   → 1200x630px, OG da pagina "Onde Comprar"
   antes-depois-1.jpg    → minimo 600x400px
   antes-depois-2.jpg    → minimo 600x400px
   antes-depois-3.jpg    → minimo 600x400px
   antes-depois-4.jpg    → minimo 600x400px
   antes-depois-5.jpg    → minimo 600x400px

IMPORTANTE:
   Se nao tiver todas as OG images, use a og-default.jpg
   para todas. Mas e melhor criar uma para cada pagina.

============================================================
PASSO 5: BUILD LOCAL (TESTAR)
============================================================

Abra o terminal na pasta do novo site. Exemplo:
   cd "C:\Users\Jefferson\Desktop\SEO LOCAL\MONJAUX\vitacaps-site"

Digite:
   npm install

Espere instalar (pode demorar 1-2 minutos).

Depois digite:
   npm run build

Verifique se aparece:
   "16 page(s) built"
   "Sitemap gerado com 15 rotas"

Se aparecer, o site esta pronto!

============================================================
PASSO 6: DEPLOY NO VERCEL
============================================================

1. Va no GitHub e crie um repositorio NOVO
   Exemplo: https://github.com/seu-usuario/vitacaps-site

2. No terminal, na pasta do site, digite:
      git init
      git add .
      git commit -m "Primeiro commit"
      git branch -M main
      git remote add origin https://github.com/seu-usuario/vitacaps-site.git
      git push -u origin main

3. Va no Vercel (vercel.com)
   - Clique em "Add New Project"
   - Importe o repositorio do GitHub
   - Clique em "Deploy"

4. Pronto! O site esta no ar.

============================================================
O QUE FAZER SE DER ERRO NO BUILD
============================================================

Erro comum 1: "Cannot find module"
   → Solucao: npm install

Erro comum 2: "images not found"
   → Solucao: coloque as imagens em public/images/

Erro comum 3: "syntax error in config.ts"
   → Solucao: verifique se o produto.json tem aspas corretas

Erro comum 4: "16 pages built" mas nao aparece
   → Solucao: verifique se o arquivo .md tem frontmatter correto
